# 14 August 2026 — Object Oriented Programming

Today I started learning **Object Oriented Programming (OOP) Lesson 09** in Python.

OOP is a new way of thinking about how programs can be structured. Instead of just writing functions and variables separately, I learned how we can group data and the functions that work with that data inside a **class**.

## What I learned today

I learned what a **class** is and how to create one in Python.

I also learned about **objects/instances**. An object is basically an instance of a class, and I can give each object its own data.

For example, I practiced creating a `Programmer` class and then created different programmer objects from it.

I also learned about the `self` parameter. `self` refers to the particular object that is using the method, which allows each object to have its own attributes.

Another thing I learned was the **constructor**, using `__init__()`. It runs when an object is created and can be used to give the object its initial values.

I also learned about **class attributes** and how they are different from instance attributes.
