## Project: Shortest Path Algorithm

Today I completed a Python project implementing **Dijkstra's shortest path algorithm** with an adjacency matrix.

### What I built
- Represented a weighted graph using a two-dimensional list.
- Used `float("inf")` for connections that do not exist.
- Tracked the shortest known distance from the starting node.
- Used a `visited` list to track processed nodes.
- Selected the unvisited node with the smallest known distance.
- Updated distances when a shorter route was found.
- Stored and displayed the actual route using a `paths` list.

### What I learned
- How an adjacency matrix represents a graph.
- How Dijkstra's greedy approach finds shortest paths with non-negative weights.
- How to track both distances and the routes used to reach nodes.
- How infinity can represent an unreachable node.
- How nested loops explore graph connections and update results.

### Example result
For the provided graph, the shortest route from node `0` to node `5` is:

```text
0 -> 2 -> 1 -> 5
```

The total distance is `6`.
