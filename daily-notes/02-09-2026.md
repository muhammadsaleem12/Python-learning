## 🤖 Auto Reply Chatbot

Today I completed another bigger Python project — an **Auto Reply Chatbot for WhatsApp**.

The idea was to combine Python automation with AI. The program can read a WhatsApp chat, check who sent the latest message, send the chat history to Gemini, get a generated response, and then automatically paste and send that response back through WhatsApp.

This project was definitely different from the smaller projects I've built so far because I had to make Python interact with things outside the program itself.

### What I worked with

* `PyAutoGUI` for mouse and keyboard automation
* `Pyperclip` for copying and pasting text
* Google Gemini API for generating replies
* `python-dotenv` for keeping the API key in `.env`
* Multiple Python files working together
* Functions and conditional logic
* Loops and automation
* Reading and processing chat history

### What I learned

One of the biggest things I learned from this project is how powerful Python can become when it is connected to other tools and services.

I also got more experience working with APIs and environment variables, while seeing how Python can control applications through keyboard and mouse automation.

The project isn't perfect yet. Since it currently relies on fixed screen coordinates, it can easily break if the browser window or screen layout changes. But for a first version, I'm happy with how it turned out.
