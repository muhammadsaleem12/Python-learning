### 🧠 Key Concepts Learned

**1. Base Case**

The condition `if len(array) <= 1:` stops recursion when the array is already sorted.

**2. Divide and Conquer**

The array is repeatedly divided into smaller parts until each part contains at most one element.

**3. Recursion**

The function calls itself to sort the left and right halves before merging them.

**4. Merging**

Two sorted halves are compared element by element. The smaller available element is placed into the original array.

**5. Index Tracking**

Three indexes track the current position in the left half, the right half, and the original array.
