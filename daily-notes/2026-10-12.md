### Key Takeaway

The biggest concept I practiced today was **hash collisions**.

Different strings can produce the same hash value. For example, `"cat"` and `"act"` have the same hash in this implementation because the hash function simply adds their character values.

To handle this, the program stores multiple keys in a nested dictionary under the same hash value. This allows each key to retain its own value.

I also practiced making the `remove()` and `lookup()` methods safely handle keys that do not exist.
