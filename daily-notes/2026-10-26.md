# Daily Python Note — 26 October 2026

## Project: Tower of Hanoi

Today I completed the Tower of Hanoi solver for my freeCodeCamp Python certification practice.

### What I built
- Created three rods as Python lists.
- Wrote a nested `helper()` function to solve the puzzle recursively.
- Used `pop()` to remove the top disk and `append()` to place it on another rod.
- Recorded the full rod arrangement after each move.
- Used `nonlocal moves` so the helper function could update the result string.
- Used `rstrip("\n")` to remove the extra newline at the end without removing line breaks between moves.

### Key idea I learned
Recursion breaks a big task into smaller versions of the same task. The helper moves smaller disks aside, moves one disk to its destination, and then moves the smaller disks onto that destination. The base case (`num_disks == 0`) stops the recursive calls.

### Important detail
For `n` disks, the puzzle needs `2**n - 1` moves. Because the output also includes the starting arrangement, it contains `2**n` arrangements.
