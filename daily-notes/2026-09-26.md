## Salary Tracker

Completed a new Python project: **Salary Tracker**.

This project focused heavily on object-oriented programming, especially **properties, getters and setters, class attributes, validation, and controlled attribute changes**.

I created an `Employee` class with different employee levels and their corresponding minimum salaries. The program automatically assigns a salary based on the employee's level and updates the salary when the employee is promoted.

I also added validation to prevent invalid names, levels, duplicate level selections, promotions to lower levels, and salaries below the minimum allowed for an employee's level.

The project also gave me more practice with `__str__`, `__repr__`, `hasattr()`, dictionaries, `TypeError`, and `ValueError`.

One of the main things I understood better through this project was how **property setters can control what happens when an attribute is changed**. Instead of simply changing a value, the setter can validate it and perform other actions before storing it.

This was another good step in getting more comfortable with Python OOP and building classes that actually enforce rules rather than just storing data.
