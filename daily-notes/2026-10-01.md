## Media Catalogue

Completed a new Python project: **Media Catalogue**.

The project manages movies and TV series using object-oriented programming. I created a `Movie` parent class and a `TVSeries` child class that inherits from it and adds seasons and episode information.

I also created a `MediaCatalogue` class that stores different media objects and separates movies and TV series when displaying them.

This project gave me more practice with **inheritance, `super()`, custom exceptions, `try` / `except`, validation, `isinstance()`, lists of objects, list comprehensions, `enumerate()`, and `__str__`**.

One of the main things I practiced was using inheritance to avoid repeating common movie-related code in the `TVSeries` class.

I also created a custom `MediaError` exception and used it to handle invalid objects being added to the catalogue.

This project helped me get more comfortable combining multiple OOP concepts into a single program instead of practicing each concept separately.
