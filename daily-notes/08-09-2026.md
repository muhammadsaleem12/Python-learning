## ⚙️ User Configuration Manager

Today I completed another Python project — a **User Configuration Manager**.

The project is a small utility that manages user settings stored inside a dictionary. I created separate functions to **add, update, delete, and view** settings.

It was a good practical exercise because I had to use the concepts I've been learning together instead of just writing isolated examples.

### What I Practiced

* Dictionaries
* Functions
* Conditional statements
* Loops
* Tuples
* Dictionary methods
* Adding and deleting dictionary items
* String methods like `.lower()` and `.capitalize()`
* Returning values from functions

I also practiced handling situations where a setting already exists or doesn't exist, rather than blindly changing the dictionary.

### What I Learned

This project helped me become more comfortable using dictionaries as actual data storage and writing functions that perform specific operations on that data.

It's a relatively small project, but that's exactly what I want from these exercises right now — **keep writing Python, keep using the syntax, and keep reinforcing the fundamentals while going deeper with FreeCodeCamp.**
