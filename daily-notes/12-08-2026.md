# 12 August 2026 — File Input & Output

Today I learned about **File Input and Output (File I/O)** in Python.

Until now, most of the programs I had written were working with data while the program was running. Today I learned how Python can actually **create, read, write, and modify files**.

## What I learned

I learned about the `open()` function and how it is used to open a file.

The basic structure is:

```python
with open("file.txt", "r") as f:
    content = f.read()
```

I learned about the different file modes:

* `r` → read
* `w` → write
* `a` → append

I also learned that using:

```python
with open(...)
```

is a better way of working with files because Python automatically handles closing the file when I'm finished with it.

### Reading files

I learned how to read the contents of a file using:

```python
f.read()
```

and how Python can retrieve information that was already stored inside a file.

### Writing files

I learned how to write information into a file:

```python
with open("file.txt", "w") as f:
    f.write("Hello World!")
```

The `w` mode creates the file if it doesn't exist, but it can also **overwrite existing content**, which is something I need to remember.

### Appending

I also learned about `a` mode.

Appending allows me to add new information to an existing file without replacing what is already there.

```python
with open("file.txt", "a") as f:
    f.write("\nNew information")
```

## What I practiced

I practiced creating files, writing information into them, reading their contents, and appending new information.

I also worked with generating information using Python and saving that information into files.

This made File I/O feel more practical because I could see how Python could be used to automate tasks involving files.

## Something important I learned

One thing I had to understand was the difference between **writing** and **appending**.

If I use:

```python
"w"
```

the existing contents can be replaced.

If I use:

```python
"a"
```

new content is added to the end of the existing file.

That's something I definitely need to remember.
