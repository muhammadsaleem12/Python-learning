## Budget App

Completed a new Python project: a **Budget App**.

The project uses a `Category` class to manage different budget categories and their transactions. I implemented deposits, withdrawals, balance checking, transfers between categories, and formatted ledger output.

I also created a `create_spend_chart()` function that calculates spending percentages across categories and generates a vertical chart showing the results.

This project gave me more practical experience with **OOP, lists, dictionaries, loops, functions, string formatting, calculations, and objects interacting with other objects**.

The `transfer()` functionality was particularly useful for understanding how one object can work with another object while keeping both objects' data updated.

Another good part of the project was building the spending chart manually with loops and string formatting instead of relying on a charting library.

This was a good step toward handling larger programs where different pieces of data and objects have to work together.
