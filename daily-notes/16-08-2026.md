# 16 August 2026 — Inheritance & More OOP

Today I continued learning **Object Oriented Programming (OOP)** in Python.

This was the next chapter after learning the basic OOP concepts like classes, objects, constructors, and the `self` parameter. This time I started learning how classes can inherit from each other and some more advanced OOP features in Python.

## What I learned

Today I learned about:

- Inheritance
- Multiple inheritance
- Multilevel inheritance
- The `super()` method
- Class methods
- Property decorators
- Operator overloading

### Inheritance

I learned how one class can inherit properties and methods from another class.

I practiced this by creating a `twoDVector` class and then creating a `threeDVector` class from it.

This helped me understand that I don't always have to write everything again in a new class when I can inherit what I already have.

### Multiple and Multilevel Inheritance

I also learned about multiple inheritance and multilevel inheritance.

One of the examples I practiced was:

    Animals
       ↓
      Pets
       ↓
      Dog

This helped me understand how classes can be built on top of other classes.

### `super()`

I learned about the `super()` method and how it can be used to access the parent class.

I used it in the 3-D vector example to use the constructor of the 2-D vector instead of rewriting the same code.

### Class Methods

I learned about class methods and how they are connected to the class rather than a specific instance.

This was one of the concepts that I found a little difficult to understand at first, so I know I need more practice with it.

### Property Decorators

I learned about the `@property` decorator and how a method can be accessed like an attribute.

I also practiced using a property setter to change another value when the property is changed.

This was another part of the lesson that took some time to understand.

### Operator Overloading

I also learned about operator overloading.

This allows us to define how operators such as `+` and `*` should behave when they are used with objects created from our own classes.

I practiced this by creating a `Complex` class and a `Vector` class.

For example, I overloaded `__add__()` to add two objects and `__mul__()` to multiply them.

I also practiced `__str__()` and `__len__()` to control what happens when an object is printed or when `len()` is used on it.
