## Project: Discount Calculator

Today I worked on a **Discount Calculator** project in Python.

The project calculates the best possible price for a product by checking multiple discount strategies. I implemented percentage discounts, fixed-amount discounts, and a special discount for premium users.

### What I Practiced

* Creating classes and objects
* Using inheritance
* Working with abstract base classes
* Using `@abstractmethod`
* Implementing different discount strategies
* Using polymorphism
* Working with type hints
* Using loops and conditions
* Comparing multiple prices with `min()`

### Key Takeaway

The main thing I practiced today was how different classes can follow the same structure while implementing their own behavior.

The `DiscountEngine` can work with different discount strategies without needing to know the specific details of each one. This helped me understand how **abstraction, inheritance, and polymorphism** can be used together to build more flexible Python programs.
