## 📧 Email Simulator

Today I completed another Python project — an **Email Simulator**.

The project simulates a simple email system where users can send emails to each other, receive them in their inbox, read them, and delete them.

This was a good OOP practice project because I had to think about how different objects would interact with each other instead of just writing individual functions.

### What I Worked On

I created three main classes:

* `User` — represents the people using the system
* `Inbox` — manages the emails belonging to a user
* `Email` — represents an individual email

A `User` has an `Inbox`, and the inbox stores multiple `Email` objects.

I also added things like read/unread status, timestamps, email numbering, and validation for invalid email numbers.

### What I Practiced

* Classes and objects
* Constructors
* Instance attributes and methods
* Object relationships
* Lists of objects
* `__str__`
* `datetime`
* `enumerate()`
* Conditional logic
* Index validation
* Functions and method calls

### What I Learned

This project helped me understand OOP in a more practical way.

Instead of just learning what a class or object is, I had to decide **which classes I needed, what information each object should hold, and how the objects should interact with one another**.

I'm starting to see how OOP can be used to structure larger programs rather than just being another Python topic to memorize.
