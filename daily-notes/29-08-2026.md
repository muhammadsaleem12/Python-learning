# 29 August 2026 — Jarvis Voice Assistant

Today I finished working on one of my first bigger Python projects — **Jarvis**, a personal voice assistant.

This project was different from the smaller practice projects I've been doing because I had to bring multiple things together into one working program.

## What I built

Jarvis can listen for the wake word **"Jarvis"**, take voice commands, and perform different tasks.

It can:

* Open websites using voice commands
* Play songs from a custom music library
* Get the latest news
* Speak responses using text-to-speech
* Send commands it doesn't recognize to Gemini AI

I also separated the project into different files instead of putting everything into one file.

`main.py` handles the main assistant and commands, `client.py` handles the Gemini AI connection, and `musicLibrary.py` stores the music links.

## What I learned

While building Jarvis, I got practical experience working with:

* Python modules and imports
* APIs
* Environment variables
* `.env` files
* `requests`
* Speech recognition
* Text-to-speech
* External Python libraries
* Virtual environments
* `requirements.txt`
* Exception handling
* Git and GitHub

One important thing I learned was how to keep API keys outside the actual code using environment variables. I also learned why sensitive files like `.env` should never be pushed to GitHub.

## The project

This started from a learning exercise, but it became much bigger once I started adding different features and connecting everything together.

It wasn't always straightforward, especially when dealing with different libraries and getting the voice and API parts working together, but solving those problems was probably the most useful part of the project.

I'm not considering Jarvis finished forever. As I learn more Python, I can come back and improve it with better features and cleaner code.

For now, I'm happy with what I built and with how much I learned from putting everything together.

**This is probably my biggest Python project so far, and it feels good to see the things I've been learning actually come together in something that works.**
