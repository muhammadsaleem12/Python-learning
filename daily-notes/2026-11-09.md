# Daily Python Note — 9 November 2026

## Project: Breadth First Search Algorithm

Today I completed a Python project that generates all valid combinations of a given number of pairs of parentheses.

### What I built
- Added input validation to check that `pairs` is an integer and at least `1`.
- Created a queue to store combinations that still need to be explored.
- Stored three values in each queue item: the current string, opening parentheses used, and closing parentheses used.
- Used a `while` loop to process the queue until no combinations remained.
- Added opening parentheses only while the opening limit had not been reached.
- Added closing parentheses only when there were more opening than closing parentheses.
- Saved a combination when its length reached `2 * pairs`.

### What I learned
- How breadth-first search explores possible states using a queue.
- How tuples keep related state information together.
- How counters can enforce rules while building a result.
- How to avoid generating invalid combinations instead of generating everything and filtering afterward.
- Why closing parentheses must never outnumber opening parentheses at any point in a valid sequence.

### Example results

For two pairs:

```text
(())
()()
```

For three pairs:

```text
((()))
(()())
(())()
()(())
()()()
```
