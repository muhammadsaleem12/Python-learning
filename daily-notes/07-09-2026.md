## 🏥 Medical Data Validator

Today I completed another Python project — a **Medical Data Validator**.

The goal of the project was to validate a collection of medical records and make sure the data follows the expected structure and format.

This project was a good continuation of my FreeCodeCamp Python practice because it made me use several concepts together instead of practicing them separately.

### What I Worked On

The validator checks the data at different levels.

First, it checks the **structure**:

* The overall data must be a list or tuple
* Each record must be a dictionary
* Each dictionary must contain the expected keys

Then it checks the **values** inside each record:

* Patient IDs and visit IDs must follow a specific pattern
* Age must be an integer and at least 18
* Gender must be `male` or `female`
* Diagnosis must be a string or `None`
* Medications must be a list containing strings

I also used **regular expressions** to validate the patient and visit IDs.

### What I Learned

One thing that became clearer to me through this project is the difference between checking the **structure of data** and checking the **values inside that structure**.

I also got more practice with things like:

* `isinstance()`
* Regular expressions
* Sets
* `enumerate()`
* `all()`
* List comprehensions
* Dictionary unpacking with `**`
* Boolean conditions
* Functions and loops

The project was a good exercise in putting these concepts together into something that actually solves a practical problem.
