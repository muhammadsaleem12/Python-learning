# Python Learning Journey 🐍

Welcome to my Python learning repository.

This repository documents my journey of learning Python from the fundamentals onward. It contains the concepts I have studied, practice problems I have solved, projects I have built, and daily notes documenting my progress.

My goal is not just to learn Python syntax, but to understand **how Python works, how to solve problems with it, and how to build real projects independently.**

## 📚 How I'm Learning

I am learning Python progressively, starting with the fundamentals and building my knowledge through practice and projects.

My learning process generally follows this cycle:

```text
Learn a concept
      ↓
Practice the concept
      ↓
Solve problems
      ↓
Build something with it
      ↓
Review mistakes
      ↓
Move on to the next concept
```

I believe that writing code and solving problems is an important part of learning, so this repository contains both my learning exercises and the projects I build along the way.

## 💻 Getting Started

If you would like to explore this repository or run the code yourself, you can clone it using Git.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/python-learning.git
```

Replace `YOUR-USERNAME` with my GitHub username.

### 2. Enter the repository

```bash
cd python-learning
```

### 3. Run a Python file

For example:

```bash
python learning/07-functions-and-recursion/practice.py
```

Or run one of the projects:

```bash
python practice_projects/02-snake-water-gun/main.py
```

> Some files may require a specific Python version or additional setup as the repository grows.

## 🐍 Requirements

Python 3 is required to run the code in this repository.
