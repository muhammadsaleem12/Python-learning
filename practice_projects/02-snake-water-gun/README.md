# 🐍💧🔫 Snake Water Gun Game

A simple CLI implementation of the classic **Snake Water Gun** game (similar to Rock-Paper-Scissors) built with Python using the `random` module.

---

## 📜 Game Rules

* **Snake vs Water:** Snake drinks Water $\rightarrow$ **Snake Wins**
* **Water vs Gun:** Water douses Gun $\rightarrow$ **Water Wins**
* **Gun vs Snake:** Gun shoots Snake $\rightarrow$ **Gun Wins**

---

## 🎮 How to Play

1. Run the script:
   ```bash
   python main.py
   ```

2. Enter your choice when prompted:
   - `s` for Snake
   - `w` for Water
   - `g` for Gun
   
3. The game will display both choices and declare the winner.

4. The game will end after one round.
