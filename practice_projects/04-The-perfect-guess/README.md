# Perfect Guess

A simple Python guessing game I made while practicing Python.

The program generates a random number between 1 and 100 and asks the user to guess it.

- If the guess is too high, it says **"Lower Number Please"**
- If the guess is too low, it says **"Higher Number Please"**
- When the correct number is guessed, it shows how many attempts it took.

## What I practiced

- `random` module
- `while` loops
- `if`, `elif` conditions
- User input
- Counting attempts

## How to run

Run the Python file:

```bash
python main.py
